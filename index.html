The improvements arc

  1. Run 2 → Run 3: priming works on the surface. Code-switching 84% → 98% published, Sheng 23% → 90% published, humour arrives, posts get punchier. But grammar stays broken and one seed (“marriage of convenience”) absorbs 21 of 37 quotes.
  2. Run 3 → Run 4: grammar fixed, tone flips. Per-type voice references, a NEVER list of broken lines, and the stronger Muse Spark model fix the grammar — and the lean flips from conditional YES to NO on the same question, cast, and seeds. That flip is the artifact warning: a model change should not swing a debate this hard unless priors dominate. Wire takes 48 of 90 actions, so the thread reads as a newsroom.
  3. Run 4 → Kalonzo: same setup, new question. Opposition 53 vs government 10, with its own artifact warning (seeds lean opposition; the government side rides on the Ruto persona plus KBC News). The honest signal inside: the lean holds only with a jobs and cost-of-living plan.

Still open

  • 0 follows in every run — the follow graph is the next engine fix.
  • Newsroom tone: wire + institutional = 77% of Kalonzo actions. A voter cast (faction × age) is the fix, not more elite personas.
  • Sheng is thin in run 4 and Kalonzo, partly a small-lexicon measurement gap (bana, fala missed) and partly real.
  • Lean flips between runs are artifact warnings, not evidence about the real questions.
  • Blind-test ratings and the founder-set backtest bar are still pending. Until they clear, weight stays 0.
