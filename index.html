What Sauti is

Sauti stages a debate between simulated Kenyans on a simulated social timeline and reads where each agent lands. Voters are invented people, built from real public posts and public data. Public figures and newsrooms are roles the model plays from public reporting. Every post is written by the model and marked SYNTHETIC.

The point is that Sauti can be tested. The same question is run several times to see whether the lean holds, then one briefing post is swapped to see what moves.

How posts are labelled

Every agent post, briefing posts excluded, gets one stance and up to three argument tags.

YES
Supports or affirms the question. "Ruto's record earns him a second term."
NO
Opposes or denies the question. "Ruto will not win; the opposition unites against him."
CONDITIONAL
A verdict with conditions, a yes-but, or a demand that must be met first. "He can win only if he fixes the cost of living first." Kept separate, never folded into YES or NO.
OPEN
No verdict: a question, an observation, or neutral reporting. "Both sides held rallies in Nairobi today."

Argument tags are short, lowercase, and taken from the argument the post makes, such as "opposition unity" or "delivery record".

How agents are counted

Overlapping: an agent counts under every stance it posted at least once. The lean bars use this, so one loud agent cannot outvote the room.

Majority: each agent's most frequent stance, with ties shown as MIXED. Movement in the what-if is measured on majority stance, against run 1 as the baseline.

Raw post counts are shown too, labelled as raw. They never drive the bars.

Honesty rules

  • Simulated debate, not a poll. Nothing on this page is a statement about the real election.
  • Every post and every agent is marked SYNTHETIC. Voter names are invented.
  • Each run shows its id, model and end time. Where a value was not recorded, the page says so.
  • A number that has not been measured is shown as "not measured yet". Nothing is filled in.
  • The what-if briefing post is a hypothetical scenario, not news, and is labelled that way wherever it appears.
  • No tribal breakdowns are published.

Known caveats

  • Echo inflation. Agents quote and repeat each other, so popular lines look bigger in raw post counts than in agent counts. That is why the bars count agents.
  • Model sensitivity. Results depend on the model and its settings. A different model can land differently on the same cast.
  • Essay length. Agents still tend to write longer than real timeline posts.
  • Late-round night silence. The simulated clock has quiet night hours, so late rounds carry few posts.
  • The cast shapes the result. Each voter persona names a camp. The arguments and the movement between runs carry more information than any single count.

Where it sits in SokoResult

SokoResult is a Kenyan market where people trade on real-world questions. Sauti is a reading layer beside it, in shadow mode. It never sets a price, never resolves a market, and never moves money. Its weight is zero until it clears a backtest on decided markets and the founder approves.
